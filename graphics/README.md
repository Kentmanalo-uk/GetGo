# GETGO graphics

Brand graphics for launching and promoting GETGO on social media. Every image is built from an HTML template in `_source/render.mjs`, so text and layout can be changed and re-exported at the exact sizes below.

## Brand basics

| | |
|---|---|
| Name | **GETGO** (written as the GET&GO wordmark) |
| Font | Plus Jakarta Sans, ExtraBold (800) for headlines, Medium (500) for body |
| Pink (fill) | `#e0266f`: buttons, the GO box, white text on pink |
| Pink (bright) | `#ff4f9a`: icons, accents, the road motif |
| Pink gradient | `#ff7ab6` → `#ff4f9a` → `#d81b6a`: filled icons |
| Soft pink | `#fff0f6`: backgrounds |
| Ink | `#16141a`: text and dark backgrounds |
| Motif | The rider on a dashed road with speed lines (also the app's loading animation) |

## `logo/`

**The mark** is a forward-leaning ampersand, the "&" in GET & GO, with two speed lines behind it (the rider motif): getting things and going. Use it wherever the full name won't fit, such as the app icon, profile photos and favicons. The **GET&GO wordmark** is the secondary logo. The **lockup** (mark plus wordmark) is the primary logo where there's room.

| File | Use |
|---|---|
| `getgo-lockup.png`, `getgo-lockup-white.png` | Primary logo (mark + wordmark), for light / dark backgrounds |
| `getgo-icon-pink.svg` / `getgo-icon-pink-1024.png` | **Pink icon**: the mark alone in the app's pink (`#e0266f`) for white or light backgrounds. Also the browser tab icon. |
| `getgo-icon-white.svg` / `getgo-icon-white-1024.png` | **White icon**: the mark alone in white, for pink, dark or photo backgrounds |
| `getgo-app-icon.svg`, `getgo-app-icon-1024.png` | **App icon**: the white icon on an app-pink rounded tile |
| `getgo-app-icon-square-1024.png` | App icon as a full square, for app stores and platforms that round icons themselves |
| `getgo-icon-on-dark-1024.png` | Pink icon on ink |
| `profile-picture-1080.png` | **Profile photo** for Facebook, Instagram, TikTok and X (circle-safe) |
| `profile-picture-dark-1080.png` | Alternative dark profile photo |
| `profile-picture-wordmark-1080.png` | Profile photo with the GET&GO wordmark |
| `getgo-logo*.png` | GET&GO wordmark (secondary logo) on transparent, white, dark and pink |

Keep clear space around the mark of at least the height of its speed lines. Don't stretch, rotate or recolor it outside the brand pinks, ink and white.

The web app uses the pink icon as its browser tab icon (`public/favicon.svg`) and the white-on-pink app icon when installed (`pwa-*.png`, `maskable-512.png`, `apple-touch-icon.png`). All are generated by the render script.

## Editing and re-exporting

1. Edit the text or layout in `_source/render.mjs` (the `DESIGNS` list).
2. From the project folder, run:
   ```
   npm i -D playwright && npx playwright install chromium
   node graphics/_source/render.mjs            # everything
   node graphics/_source/render.mjs promotion  # only files whose path contains "promotion"
   ```

## Before posting

- The posts say "link in bio". Put your live GETGO address (your Vercel domain or custom domain) in your page bio.
- The posts mention GCash by name only. Don't add GCash's logo to promotional graphics unless you become an official GCash merchant and follow their brand guidelines.
- Don't show other businesses' logos or names (for example, stores listed on GETGO) in ads unless they're GETGO Partners who agreed to it.
