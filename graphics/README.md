# GETGO graphics

Brand graphics for launching and promoting GETGO on social media. Every image is built from an HTML template in `_source/render.mjs`, so text and layout can be changed and re-exported at the exact sizes below.

## Brand basics

| | |
|---|---|
| Name | **GETGO** (written as the GET&GO wordmark) |
| Font | Plus Jakarta Sans, ExtraBold (800) for headlines, Medium (500) for body |
| Pink (fill) | `#e0266f`: buttons, the GO box, white text on pink |
| Pink (bright) | `#ff4f9a`: icons, accents, the road motif |
| Pink gradient | `#ff7ab6` → `#ff4f9a` → `#d81b6a`: filled icons |
| Soft pink | `#fff0f6`: backgrounds |
| Ink | `#16141a`: text and dark backgrounds |
| Logo | The GO logo: two linked rings with an arrow running through them |
| Motif | The rider on a dashed road with speed lines (also the app's loading animation) |

## `logo/`

**The official logo** is the GO mark: two linked rings, the G and the O, with an arrow running through them. The originals are `pink-icon.jpg` and `white-icon.jpg`. The SVG files are an exact vector rebuild of them, in the app's pink (`#e0266f`). Use the logo wherever the full name won't fit, such as the app icon, profile photos and favicons. The **GET&GO wordmark** is the secondary logo. The **lockup** (logo plus wordmark) is the primary logo where there's room.

| File | Use |
|---|---|
| `pink-icon.jpg`, `white-icon.jpg` | The original logo files |
| `getgo-lockup.png`, `getgo-lockup-white.png` | Primary logo (logo + wordmark), for light / dark backgrounds |
| `getgo-icon-pink.svg` / `getgo-icon-pink-1024.png` | **Pink icon**: the logo alone in the app's pink (`#e0266f`) for white or light backgrounds. Also the browser tab icon. |
| `getgo-icon-white.svg` / `getgo-icon-white-1024.png` | **White icon**: the logo alone in white, for pink, dark or photo backgrounds |
| `getgo-app-icon.svg`, `getgo-app-icon-1024.png` | **App icon**: the white icon on an app-pink rounded tile |
| `getgo-app-icon-square-1024.png` | App icon as a full square, for app stores and platforms that round icons themselves |
| `getgo-icon-on-dark-1024.png` | Pink icon on ink |
| `profile-picture-1080.png` | **Profile photo** for Facebook, Instagram, TikTok and X (circle-safe) |
| `profile-picture-dark-1080.png` | Alternative dark profile photo |
| `profile-picture-wordmark-1080.png` | Profile photo with the GET&GO wordmark |
| `getgo-logo*.png` | GET&GO wordmark (secondary logo) on transparent, white, dark and pink |

Keep clear space around the logo of at least the thickness of its rings. Don't stretch, rotate or recolor it outside the brand pinks, ink and white.

The web app uses the pink icon as its browser tab icon (`public/favicon.svg`) and the white-on-pink app icon when installed (`pwa-*.png`, `maskable-512.png`, `apple-touch-icon.png`). All are generated by the render script.

## `promotion/`

Launch posts for Facebook and Instagram. 1080×1080 is square, 1080×1350 is portrait (best for the feed), and 1080×1920 is for Stories and Reels.

The posts use an ad style: a full pink background with diagonal ink or white blocks, big uppercase headlines with one word in a tilted box, a large outlined word in the background, a phone showing the GETGO app, floating cards, a starburst sticker and a pill "Order now" button. The phone screens are mock-ups of the real app; the store names, items, prices and rider are made up, so no real business or person appears. The templates are in `_source/promo.mjs`.

| File | Message |
|---|---|
| `01-launch-square-1080.png` | GETGO is here, Bongabong! |
| `02-launch-story-1080x1920.png` | Pabili. Padala. Errands. GETGO na! (Story) |
| `03-services-1080x1350.png` | One app, four services |
| `04-how-it-works-1080x1350.png` | Order, a rider accepts, delivered |
| `05-pay-your-way-1080x1080.png` | GCash or cash on delivery |
| `06-ride-with-getgo-1080x1350.png` | Rider recruitment |
| `07-partner-with-getgo-1080x1350.png` | Store partner recruitment |
| `08-padala-errands-1080x1080.png` | Padala and errands |

Each post has a caption in a text file with the same name (for example `01-launch-square-1080.txt`). The Facebook Page bio, About text and settings are in `bio.txt`.

## Editing and re-exporting

1. Edit the text or layout in `_source/render.mjs` (the `DESIGNS` list) or, for the launch posts, `_source/promo.mjs`.
2. From the project folder, run:
   ```
   npm i -D playwright && npx playwright install chromium
   node graphics/_source/render.mjs            # everything
   node graphics/_source/render.mjs promotion  # only files whose path contains "promotion"
   ```

## Before posting

- The posts say "link in bio". Put your live GETGO address (your Vercel domain or custom domain) in your page bio.
- The posts mention GCash by name only. Don't add GCash's logo to promotional graphics unless you become an official GCash merchant and follow their brand guidelines.
- Don't show other businesses' logos or names (for example, stores listed on GETGO) in ads unless they're GETGO Partners who agreed to it.
